# SkillForge: AI-Powered Student Skills & Career Development Platform

SkillForge is a comprehensive platform designed to guide students through career planning, skill gap analysis, and learning roadmaps using AI.

## Project Structure

- `client/`: React (Vite) Single Page Application frontend.
- `api-gateway/`: Node.js/Express API Gateway & Authentication Proxy.
- `ai-service/`: Python (FastAPI) Microservice for AI Agents and RAG.
- `devops/`: Deployment, Kubernetes, and Terraform infrastructure files.
- `.github/`: GitHub Actions workflows for CI/CD.

## Getting Started

To run the frontend client locally:
```bash
cd client
npm install
npm run dev
```
